# Примерка профессий

Профориентация для подростков: 30 вопросов по модели Холланда, оценки по предметам,
результат и 30 карточек профессий, написанных языком подростка.

Приложение — в папке `app/`. Ответы хранятся только в браузере пользователя
и никуда не отправляются.

Вопросы составлены по мотивам O*NET Mini Interest Profiler (U.S. Department of Labor),
используются по O*NET Tools Developer License; изменены для подростков.
